# Mamta General Store

E-commerce website for **Mamta General Store**, starting with a **Ladies' Suits**
collection and built to grow with more product categories over time.

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS v4 + [shadcn/ui](https://ui.shadcn.com) components
- [Prisma](https://www.prisma.io) ORM 7 with PostgreSQL (driver-adapter setup)
- ESLint + Prettier

## Getting started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Configure environment — copy the template and edit the values:

   ```bash
   cp .env.example .env
   ```

   - `DATABASE_URL` — PostgreSQL connection string
   - `NEXT_PUBLIC_SITE_URL` — public base URL (used for SEO metadata, sitemap, robots)

3. Create the database schema once a PostgreSQL server is running:

   ```bash
   npx prisma migrate dev --name init
   ```

4. Start the dev server:

   ```bash
   npm run dev
   ```

## Scripts

| Command                | Purpose                                   |
| ---------------------- | ----------------------------------------- |
| `npm run dev`          | Start the development server              |
| `npm run build`        | Generate Prisma Client + production build |
| `npm run start`        | Run the production build                  |
| `npm run lint`         | Run ESLint                                |
| `npm run lint:fix`     | Run ESLint with auto-fix                  |
| `npm run typecheck`    | Run TypeScript checks (no emit)           |
| `npm run format`       | Format files with Prettier                |
| `npm run format:check` | Check formatting in CI                    |

## Project structure

```
src/
├── app/                 # Routes (App Router): pages, SEO files
│   └── category/[slug]/ # Data-driven category pages
├── components/
│   ├── ui/              # shadcn/ui primitives (button, card, ...)
│   ├── layout/          # Header, footer, nav (added in next steps)
│   ├── product/         # Product cards, grids, galleries
│   ├── cart/            # Cart & checkout UI
│   └── admin/           # Admin-only UI (keep behind auth)
├── config/              # Site metadata & navigation definitions
├── lib/                 # Prisma client, utils, shared constants
└── types/               # Shared domain types (Product, Category, ...)
```

- **Generated Prisma Client** lives in `src/generated/` (gitignored); it is
  regenerated by `prisma generate` / `npm run build`.
- **`prisma/schema.prisma`** is category-driven: adding a future category is a
  data change (a new `Category` row), not a code change.

## Adding a new product category (later)

1. Insert a `Category` row (e.g. via admin UI or seed) — products link to it.
2. Add a navigation entry in `src/config/navigation.ts`.
3. Optionally extend `src/app/sitemap.ts`.

No schema or route changes are needed — `/category/[slug]` handles any category.
